# 发布版四人服装与办公动作

四人沿用已经验证的 1.75 米成人底模和 53 骨骼。发布版用袖管与连续衣身裁切、发型配饰、眼镜、领带和工牌建立可辨认的身份；三位领导保持站姿办公，以保留 P4 已验收的视线高度与掩体关系。

| 身份 | 外观轮廓与配饰 | 办公动作 |
|---|---|---|
| 玩家 | 浅色带领短袖，青色挂绳与工牌，深蓝长裤 | 原有 idle / walk / run / crouch_idle / crouch_walk / roll 六动作 |
| 工位组长 | 棕色 V 领针织背心，圆框眼镜，灰棕短发，口袋笔 | 双手交替敲键盘 |
| 办公室主管 | 蓝色马甲、浅色七分袖，低束发结与领针 | 左手持蓝文件夹，右手翻阅 |
| 楼梯口经理 | 深灰长袖西装、翻领、酒红领带，方框眼镜与银灰短发 | 左手持夹板，右手记笔记 |

## 可重建来源

不需要运行 Blender 或下载新素材。三个 Godot 脚本就是服装和动作的可编辑源文件，每次实例化都会从原始 GLB 确定性构建：

- `../../../game/scripts/release_character.gd`：四套服装。马甲／西装在原连续衣物表面精确裁切领口／下摆分色边界，插值保留底模蒙皮权重，不叠加共面衣片；袖子通过两段手臂骨权重构造。头发保留原几何与 cutout，在实例私有纹理中调节色阶，不改变原 GLB。领子、工牌、眼镜等使用骨骼附件。
- `../../../game/scripts/release_guard_visual.gd`：三种办公手势，文件夹、夹板和笔。办公时钟由原 P4 状态机驱动，暂停同步停止；抬头动作的头／脊柱姿态与原版本相同。
- `../../../game/scripts/release_guard.gd`：P4 领导 AI 的表现子类，只替换服装和手势。不增加追逐、领导信息共享或额外感知。

同一骨骼上的小配饰按顶点颜色合并为一个网格；一份文件也合并为一个网格。所有新材质注册到原 actor 的镜头淡出系统，不会出现身体变透明而配饰仍挡镜头的情况。衣服、眼镜和文件只提供渲染表现，不引入新的视线遮挡墙。

## 验证

在项目根目录执行，`--script` 请使用本机绝对路径：

```bash
bash tools/godot.sh --headless --fixed-fps 60 --script /absolute/xiaban/art/characters/release/validate.gd
bash tools/godot.sh --resolution 1600x900 --script /absolute/xiaban/art/characters/release/inspect.gd -- --output=/absolute/output
```

`validate.gd` 会更新本目录 `validation.json`，校验重复应用、53 骨骼、六动作、材质淡出往返、玩家新增附件在六动作的实际骨骼变换，以及三位领导低头、半抬头、抬头时相对 P4 的眼位误差。`inspect.gd` 输出四张原生渲染陈列图，仅用于外观检查，不代替真实输入试玩。

最终服装几何验证：玩家 19,113 三角面、7 网格；组长 20,239 / 8；主管 20,469 / 9；经理 19,836 / 9。领导手持文件和笔另计少量几何。玩家新增配饰 44 三角面；翻滚期间新增配饰包络 x=[−0.159,0.167]、y=[0.225,1.178]、z=[−0.450,0.317] 米，包含在现有 1.06 × 1.55 × 2.20 米保守翻滚检查体内。三位领导在三个抬头采样姿态的眼位偏差均为 0 米。以上是逐 60 FPS 的附件采样和眼位对照，整个人体的接地与关卡动作回归由发布测试套件另行验证。
