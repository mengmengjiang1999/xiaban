# P2：运行与导出

更新日期：2026-09-22

当前默认入口是 **P2 一个人形角色与动作样板**：一个有衣发鞋的成人、六段骨骼动画、正常行走及沿用的右肩镜头。P1 胶囊原型独立保留。蹲姿碰撞、冲刺和翻滚位移属于下一阶段 P3，新领导感知属于 P4；原地动画展示不代表这些规则已实现。验证结果及平台边界见 [P2 测试记录](P2测试记录.md)。

## 2. 启动与操作

```bash
bash tools/godot.sh
```

默认启动 `game/scenes/p2.tscn`；也可显式执行 `bash tools/godot.sh res://scenes/p2.tscn`。编辑器命令为 `bash tools/godot.sh --editor`；导入 `game/project.godot` 后，按 F5 运行 P2。办公室与人形在运行时组装，编辑器初始树只显示入口节点。

点击 **开始体验** 后操作：

| 操作 | 输入 |
|---|---|
| 沿人物朝向前进／倒退 | W / S，当前样板步速 1.65 米／秒；倒退不反转身体和镜头 |
| 左右转身 | A / D，可原地转身，不作横移 |
| 环绕观察 | 按住鼠标右键拖动；不改变身体朝向或 W/S 参照 |
| 调节镜距／快速回正 | 滚轮／F，回正保留所选距离 |
| 站立／行走／跑步原地展示 | 1 / 2 / 3 |
| 蹲姿／蹲走／翻滚原地展示 | 4 / 5 / 6 |
| 返回正常行走试玩 | 0 |
| 暂停、释放鼠标 | Esc |
| 恢复 | 暂停界面点击 **点击继续** |
| 重试 | **重新开始**；完成路线后 **再走一遍** |

1–6 展示期间身体骨骼运动，玩家位置、朝向和站立碰撞体不随动作改变，W/S/A/D 暂不驱动移动。右键观察、滚轮、F 和 Esc 仍有效。暂停冻结当前动画，继续恢复同一展示；重试清除展示与残留输入。它们是样板选择键，不是 P3 最终蹲伏、冲刺和翻滚按键。

点击开始／继续后才申请鼠标捕获；Esc、失焦或失去捕获会暂停，重新聚焦不自动恢复或抢回鼠标。Esc 不用于再次继续。镜头跟随玩家实际位置和水平朝向，不跟随动画头部或翻滚旋转。

到达楼梯口结束路线体验；当前没有领导感知或追赶，这不是完整潜行通关。

## 3. 浏览器试玩与 Web 导出

```bash
bash tools/build_web.sh p2
python3 tools/serve_web.py --directory builds/p2-web --port 8767
```

服务运行时打开 [P2 本地试玩页](http://127.0.0.1:8767/)。服务器只绑定 `127.0.0.1`；Ctrl+C 停止。代码或资产修改后重新导出、刷新，页面不会自动更新。请通过 HTTP 访问，不要双击 `index.html`。

本轮输出：

- `builds/p2-web/`：运行目录，入口 `index.html`。
- `builds/xiaban-p2-web.zip`：23.64 MiB，ZIP 根目录包含入口和运行文件，附 Godot、字体及 `CHARACTER-LICENSES.txt` 人形许可。
- `Web P2` 导出预设使用 `p2` 特性固定 P2 场景。P1 的 `Web` 预设使用 `p1`，保持独立。

脚本检查 ZIP 完整性和根目录入口。ZIP 可用于后续 itch.io 上传，但当前没有创建页面或公开发布；本机与本地 iframe 结果不能替代 itch.io 真实托管验收。

### Playwright 验收

用户已授权使用独立 Playwright 与本机 Google Chrome。依赖安装在项目工具目录：

```bash
npm install --prefix .tools/browser-qa playwright
```

保持 8767 服务运行，另一个终端执行：

```bash
node tools/test_browser_p2.cjs
```

P2 脚本默认使用后台 Chrome；`P2_HEADLESS=0 node tools/test_browser_p2.cjs` 可显式开启有界面的独立测试窗口，`P2_URL=http://127.0.0.1:其他端口/` 可改服务地址。有界面测试时手动切换窗口会触发游戏安全暂停。

脚本用真实键鼠完成行走、观察、六段展示、暂停继续和办公室路线；`?p1_qa=1&p2_qa=1` 仅提供只读状态，普通试玩地址不启用。报告和截图位于 `.logs/p2-browser/`，再次运行覆盖同名结果。资源调整后的定向复验可执行 `P2_ASSET_ONLY=1 node tools/test_browser_p2.cjs`，单独输出到 `.logs/p2-browser-assets/`；此模式不重跑路线、普通 URL 和 iframe。后台模式不验证原生窗口切换、真实桌面全屏体验或 Safari，不能据此宣称这些项目已经通过。

若 Chrome 在载入游戏前的系统注册阶段退出，应保留启动日志并区分启动环境故障与游戏运行崩溃；不要只凭进程退出就改动游戏渲染配置。本轮实际经过的启动重试和错误分类见 [P2 测试记录](P2测试记录.md)。

本轮已生成 `builds/macos/XiabanP2.app`，本机签名校验及真实 OpenGL 加载检查通过。预设为 Universal、本地 ad-hoc 签名，未做 Apple 公证；本机检查不等于外部分发验收。

## 6. 保留的 P1 与历史版本

P1 胶囊入口和导出保持可独立使用：

```bash
bash tools/godot.sh res://scenes/p1.tscn
bash tools/build_web.sh p1
python3 tools/serve_web.py --directory builds/web --port 8766
```

`bash tools/build_web.sh` 不带参数仍默认导出 P1；服务脚本不带参数仍默认目录 `builds/web`、端口 8765。明确指定目录和端口可避免把旧 P1 页面误当作 P2。

P1 输出为 `builds/xiaban-p1-web.zip` 和 `builds/macos/XiabanP1.app`，Chrome、频闪修复及平台边界保留在 [P1 测试记录](P1测试记录.md)。P1 曾通过 86 项基础、8 项几何、15 项镜头稳定性和 43 项 Chrome 检查；本次为工厂方法调整重跑了 86 项基础回归，不重复宣称其余历史测试是本轮新执行。

旧斜俯视 v0.1 可显式运行 `bash tools/godot.sh res://scenes/main.tscn`，测试入口为 `res://tests/level_test.gd` 和 `res://tests/playthrough.gd`。其追赶、抓捕、世界坐标移动属于 [历史试玩说明](第一关试玩说明.md)，不能用于当前新规则验收。
