## 2. 正式第一关启动与操作

```bash
bash tools/godot.sh
```

默认启动 `game/scenes/release.tscn`，也可显式执行 `bash tools/godot.sh res://scenes/release.tscn`。编辑器命令为 `bash tools/godot.sh --editor`；导入 `game/project.godot` 后，按 F5 运行正式第一关。办公室和人物在运行时组装，编辑器初始树只显示入口节点。

| 操作 | 输入与当前行为 |
|---|---|
| 前进／倒退 | W / S，沿人物朝向；倒退不反转身体和镜头 |
| 左右转身 | A / D，可原地转身，不作横移 |
| 蹲下／尝试站起 | C；完整起身空间不足时维持蹲姿 |
| 冲刺 | 站姿按住 Shift + W；蹲姿需先 C 站起，Shift 不自动起身；脚步声可能引起领导注意 |
| 翻滚 | 蹲姿按 Space，朝开始时的人物正前方滚动；锁向且不能手动取消，受阻停位移并播完剩余动作，再恢复为蹲姿；动作安静但仍可能被看见 |
| 自由观察 | 方向键 ←→ 左右环绕、↑↓ 上下俯仰；保留按住右键上下左右拖动，不改变人物或 W/S 参照 |
| 调节镜距／快速回正 | 滚轮／F；F 恢复人物后方与默认 14° 俯角，保留所选距离 |
| 暂停、释放鼠标 | Esc |
| 恢复／重试 | 暂停界面明确继续；结算或暂停界面重新开始 |
| 游戏音量 | 菜单或暂停界面，0～100%；0 为静音 |
| 鼠标观察灵敏度 | 菜单或暂停界面，0.5～2.0 倍 |

松开方向键或右键后暂留视角 1.25 秒；未继续移动或转身则保留。移动触发回正后会平滑完成，方向键或右键观察可随时打断。观察优先，WASD 始终只控制人物；迷失方向时可按 F 快速恢复肩后构图。暂留时间和速度为可调易玩辅助。

音量和灵敏度保存到本机配置；网页设置属于当前浏览器站点，清除站点存储后可能恢复默认。默认音量 65%、灵敏度 1.0 倍。环境／效果的音量设置不改变领导听觉逻辑；办公声、动作、注意与结算反馈为项目原创程序音效。

点击开始／继续后才申请鼠标捕获；Esc、失焦或失去捕获会暂停，重新聚焦不自动恢复或抢回鼠标。暂停同时冻结玩家、三位领导的姿态与独立计时；重新开始恢复起点和各自的初始工作进度。镜头跟随玩家实际位置与水平朝向，不继承动画头部高度或翻滚旋转。

路线依次经过工位组长、办公室主管、楼梯口经理。进入每段先到高柜后观察，等领导低头后再蹲着走向矮柜；到柜端或门口重新观察、等待时机，再用 A/D 摆正人物朝向后翻滚。高柜与矮柜之间并非连续遮挡，低姿态本身不保证安全。连接走廊交替转向，进入下一段后需重新观察。

领导低头时不观察，抬头动作提供提前线索，仅观察阶段启用视觉发现。黄色地面提示当前观察方向，按站／蹲／翻滚状态使用稳定的连续高度包络与真实遮挡采样；它是粗略方向提示，最终发现仍由实际动画头胸射线决定。持续看见到确认阈值才失败，重新藏住清空未完成确认。冲刺声由三位领导分别判断距离，范围内才抬头转向记录声源；听见本身不判失败，也不追逐。一次反应中连续脚步不会无限重启抬头或实时追踪藏住的玩家。翻滚安静，但身体露出仍可能被发现。

开放桌底仅禁止通行，视线按实际桌面、桌腿和设备判断，不形成不可见的整块遮挡墙。正式版保留 P4b 的全部碰撞体和路线；墙面、木饰面、地毯、地砖及壁面装饰用于提升辨识，不改变掩体高度与通路。

## 3. 正式浏览器试玩与 Web 导出

```bash
bash tools/build_web.sh release
python3 tools/serve_web.py --directory builds/release-web --port 8772
```

服务运行时打开 [正式第一关本地试玩页](http://127.0.0.1:8772/)。服务器只绑定 `127.0.0.1`；Ctrl+C 停止。修改代码或资产后需重新导出并刷新，页面不会自动更新。请通过 HTTP 访问，不要双击 `index.html`。

| 产物或预设 | 用途 |
|---|---|
| `builds/release-web/index.html` | 正式第一关浏览器入口 |
| `builds/xiaban-release-web.zip` | 正式上传包路径，根目录包含入口、运行文件与许可说明 |
| `Web Release` | 使用 `release.tscn`，版本 `1.0.1` |
| `Web P4 Full` | 独立 `p4b` feature，保留 `p4b.tscn` 与版本 `0.6.0-p4` |
| `Web P4` | 独立 `p4` feature，保留 P4a 单领导场景 |
| `Web` / `Web P2` / `Web P3` | 分别保留 P1／P2／P3 独立场景 |

脚本检查 ZIP 完整性和根目录入口，并附字体及人物许可；`build_release.sh` 另核对 Web 与原生 PCK 一致性。机器可读清单为 `builds/release-manifest.json`，版本从工程读取。本轮结果写入 [稳定性测试记录](发布前稳定性测试记录.md)，旧摘要保留在 1.0.0 历史记录。当前尚未上传或公开；本地页面及 iframe 检查不能替代实际 itch.io 托管验收。

普通试玩地址不启用验收状态；自动化检查添加 `?p1_qa=1&p3_qa=1&p4b_qa=1&release_qa=1`，仅允许读取状态，不通过它移动玩家或改变领导。保持 8772 服务运行后执行：

```bash
node tools/test_browser_release.cjs
```

浏览器脚本使用已获用户授权的 Playwright 与 Google Chrome，依赖位于 `.tools/browser-qa/`。`RELEASE_HEADLESS=0` 使用有界面窗口，`RELEASE_URL` 改地址，`RELEASE_FINAL_ONLY=1` 复核最终包完整路线，`RELEASE_SMOKE_ONLY=1` 检查普通启动和本地 iframe。报告分别保存于 `.logs/release-browser/`、`.logs/release-browser-final/` 与 `.logs/release-browser-smoke/`。

当前 1.0.1 冻结包已通过 Chrome 镜头／提示专项 32／32、最终路线与渲染复核 34／34、普通启动与嵌入 13／13，三轮分开计数；真实路线 121.150 秒、58.403 米。8 秒取样 60 FPS，P95 18.7 ms、最大 18.8 ms；两轮贴墙淡出无录屏检查最大均 18.7 ms、没有超过 40 ms 的帧。原生提示 73／73、270 帧与最终导出应用启动通过，完整范围和实载摘要见 [稳定性记录](发布前稳定性测试记录.md)。

以下为 **1.0.0 历史基线**，不代表本轮 1.0.1：Chrome 完整检查 **67／67 通过**，另轮菜单定向检查 **26／26 通过**，两轮不相加。实际键鼠通关 128.800 秒、58.414 米，分别由三位领导发现的失败流程均通过。三位领导正常运行的 8.0157 秒采样中记录 481 帧，平均 60.007 FPS，帧间隔 P95 为 17.6 ms、最大 17.7 ms；这是当前机器和采样窗口的结果，不是所有设备性能承诺。

1.0.0 真实 Safari **26.6.2** 完成加载、持续运行 56.37 秒、C 蹲起、Space 翻滚 2.4 米、Esc 暂停／继续、全屏进退及切标签暂停烟测。未做完整通关与失败；后期原生截图工具出现 `SC -3811`，普通页后续操作未能复核，因此不能宣布完整 Safari 整关兼容。Chrome、真实 Safari、摆位画面和同引擎 WebKit 测试的证据分别记载；Windows 无本次实机验证，手机触屏不支持。
