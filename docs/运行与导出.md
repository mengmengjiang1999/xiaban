- 已安装匹配的单线程 Web Debug/Release 和 macOS 导出模板，未安装其他平台模板。
- 模板目录：`~/Library/Application Support/Godot/export_templates/4.7.2.stable/`。
- 工程目录：`/Users/mmj/Projects/other/office-escape/game/`。

后续移动 Godot 到“应用程序”后，辅助脚本仍会优先找到它；也可设置 `GODOT_BIN` 为实际可执行文件路径。

## 2. 在 Godot 中打开

打开 Godot 的项目管理器，选择“导入”，定位到：

```text
/Users/mmj/Projects/other/office-escape/game/project.godot
```

导入后进入编辑器，点击“运行项目”（F5；部分 Mac 键盘需 Fn+F5）。主场景已设为 `scenes/main.tscn`。

命令行方式：

```bash
cd /Users/mmj/Projects/other/office-escape
bash tools/godot.sh --editor
```

点击“开始下班”进入游戏：

- **WASD / 方向键**：移动；**Shift**：跑步。
- **Esc / 暂停按钮**：暂停或继续。
- **重新开始**：完整重置本关；结算后也可按 **R**。
- 菜单和暂停页提供音量与全屏入口。

中文字体已随工程打包，无需另行安装。首次点击开始后才触发声音。

关卡当前由脚本在运行时组装，所以编辑器场景树初始只有入口节点；按 F5 后可看到完整办公室。改地图请先看 `game/scripts/level.gd` 的墙、柜、桌坐标数组。

## 3. 浏览器试玩

启动本地服务器：

```bash
cd /Users/mmj/Projects/other/office-escape
python3 tools/serve_web.py
```

用浏览器打开 [本机测试页面](http://127.0.0.1:8765/)。服务器运行时页面才可访问，在终端按 Ctrl+C 停止。

服务器只绑定本机地址，服务目录仅为 `builds/web`。没有把工程或其他个人文件公开到网络。

如果端口已被占用，可能已有本项目服务器正在运行，可先打开页面；或者指定另一个端口：

```bash
python3 tools/serve_web.py --port 8766
```

此时访问 `http://127.0.0.1:8766/`。不要通过双击 `index.html` 来判断 Web 构建是否正常。

## 7. 常见情况

- **找不到模板**：检查版本必须是 `4.7.2.stable`；升级编辑器后需要匹配的新模板。
- **Mac arm64 纹理导出报错**：工程已启用 ETC2/ASTC 和 S3TC/BPTC 导入设置；新建工程时需注意对应平台要求。
- **网页空白**：确认通过 HTTP 地址访问，Web 使用 Compatibility、单线程、无 GDExtension，并检查浏览器控制台。
- **画面两侧或上下黑边**：游戏保持设计比例，当前属于正常留边。
- **为何没有声音**：先点击“开始下班”，检查音量滑块和系统静音；目前只有脚步、警戒和结算短音，没有背景音乐。
- **切回页面后暂停**：失去焦点时游戏会自动暂停，点击“继续下班”即可。
