# 《准点下班》第一关试玩说明（v0.1 归档）

> 本页只说明斜俯视 v0.1 的历史操作与追赶规则，不是当前 P2 人形样板或保留的 P1 镜头原型说明。新版入口和数字键原地动作展示见 [运行与导出](运行与导出.md)，状态见 [P2 测试记录](P2测试记录.md)，新规则见 [设计确认](../设计确认.md)。下文路径与构建信息保留旧版记录。

这是一个短小的 3D 办公室潜行关卡：控制准备下班的程序员，穿过工位区、办公室走廊和楼梯口，绕开三位领导，抵达绿色 **EXIT / 下班** 区域。

当前是第一关的初版，使用简单的立体人物和家具。熟悉路线后，包含观察和等待的通关实测约 30 秒；首次游玩时长尚未统计，观察、探索和重试都会影响用时。目前没有公开发布。

![第一关实机画面](images/level-one-game.png)

## 第一次玩

1. 使用电脑和键盘打开游戏，点击 **开始下班**。网页中如果按键没有反应，先点击一次游戏画面。
2. 先看领导脚边的视野扇形，再决定什么时候移动。领导转头和巡逻时，扇形也会改变。
3. 借助墙和高柜躲藏，等待领导看向别处，再穿过通道。
4. 警戒值升满后，领导会追赶。用跑步拉开距离，并寻找能挡住视线的掩体。
5. 抵达绿色出口即可成功下班。追赶中的领导近距离碰到你，会进入失败结算。

## 操作

| 操作 | 按键或按钮 |
|---|---|
| 移动 | WASD 或方向键 |
| 跑步 | 移动时按住 Shift |
| 暂停／继续 | Esc；暂停界面也有“继续下班”按钮 |
| 快速重试 | 成功或失败结算后按 R |
| 重新开始 | 暂停或结算界面的“重新开始”按钮 |
| 调节音量 | 开始菜单或暂停界面的音量滑块 |
| 全屏 | 开始菜单或暂停界面的“全屏”按钮 |

切换到其他应用或让游戏失去焦点时，游戏会自动暂停。回来后点击“继续下班”即可。

## 躲避规则

- **墙和高柜能挡视线。** 躲到它们后面，再观察下一段路线。
- **矮桌只挡路。** 站在桌子另一边，领导仍可能看见你。
- **进入视野不会立即失败。** 警戒值会增长；在警戒满之前离开视线，警戒会逐渐消退。
- **警戒满后才开始追赶。** 只从领导背后贴近，不会凭空触发抓捕。
- **追赶可以甩脱。** 躲开视线后，领导会去最后看见你的位置搜索，然后返回；掩体不是永久安全区，领导也会绕路。
- **跑步目前只影响移动速度。** 没有体力条或脚步声侦测。

## 卡住时可以试试

- 出生点附近先停一下，观察工位领导转头，再找机会穿过左侧门。
- 中段的高柜可以提供遮挡；矮桌则不能当作躲藏点。
- 楼梯口也有领导，接近出口前仍要留意扇形方向。
- 被追时先找高掩体，不必强行往出口冲。失败后可立即重试。

## 在这台 Mac 上运行

以下命令均在项目目录中执行：

```bash
cd /Users/mmj/Projects/other/office-escape
```

### 用 Godot 打开项目

```bash
bash tools/godot.sh --editor
```

打开编辑器后，点击右上方的“运行项目”，或按 F5（部分 Mac 键盘需要 Fn+F5）。

### 在浏览器里试玩

先生成网页版本：

```bash
bash tools/build_web.sh
```

然后启动本地服务器：

```bash
python3 tools/serve_web.py
```

用电脑浏览器打开 [本地试玩页面](http://127.0.0.1:8765/)。保持这个终端运行；结束试玩后可按 Ctrl+C 停止服务器。如果提示端口被占用，先尝试打开页面，已有服务器可能仍在运行。

修改游戏后，需要重新运行打包命令，再刷新网页。不要双击导出的 `index.html` 来启动游戏。

网页文件在 `builds/web/`；用于 itch.io 的上传包是：

```text
builds/office-escape-level-one-web.zip
```

生成上传包并不等于公开发布，目前尚未上传。更多运行方法见 [运行与导出](运行与导出.md)。

## 当前试玩范围

当前浏览器试玩验证范围为这台 Mac 上的 Chrome／Chromium。Safari 和 Windows 仍待验证；请不要把当前结果视为所有电脑和浏览器都已兼容。游戏按电脑键盘设计，当前未提供手机触屏操作。

试玩时最有用的反馈是：在哪里不清楚该往哪走、哪次被发现让你觉得意外、是否出现走不动或镜头看不清的情况，以及成功或失败前采取了什么动作。
