# 《下班》第一关试玩说明

更新日期：2026-09-23。对应正式第一关 `1.0.1`，本地稳定性验证完成，尚未上传。本页已替换旧 v0.1 的斜俯视与追赶规则；P1～P4 的历史测试记录保留各自当时的范围。

你是一名准备下班的程序员。穿过工位区、办公室门前和楼梯前厅，借助掩体躲开三位领导，走到绿色楼梯出口即可成功下班。

## 第一次玩

1. 使用电脑、键盘和鼠标打开游戏，点击 **开始下班**。网页需要获得键盘焦点和鼠标指针捕获权限；若按键无响应，先点击游戏画面。
2. 出发前在高柜后停一下，观察领导从低头办公到抬头巡视的节奏。
3. 遇到矮柜时按 **C** 蹲下，沿着柜子通过。站起来会露出头部或胸口。
4. 需要翻滚时，先用 **A／D** 转好人物朝向，再在蹲姿按 **Space**。镜头朝向与人物朝向可以不同。
5. 根据墙上的导向牌穿过两条转移走廊。每到新区域重新观察，最后走到绿色楼梯口。

## 操作

| 操作 | 按键或按钮 |
|---|---|
| 朝人物前方移动／倒退 | W／S |
| 向左／向右转身 | A／D；不是横向平移 |
| 切换蹲下／站起 | C |
| 冲刺 | 站立时按住 Shift + W；蹲姿按 Shift 不会自动站起 |
| 向前翻滚 | 蹲姿按 Space，沿人物开始翻滚时的朝向前进 |
| 自由观察 | 方向键 ←→ 左右环绕、↑↓ 上下俯仰；也可按住右键上下左右拖动 |
| 调整镜头距离 | 鼠标滚轮 |
| 镜头回正 | F；回到人物后方与默认俯角，保留镜距 |
| 暂停 | Esc |
| 继续 | 暂停界面的“点击继续”按钮 |
| 重新开始／返回菜单 | 暂停或结算界面的对应按钮 |
| 音量 | 菜单或暂停界面，0～100%；0 为静音 |
| 鼠标观察灵敏度 | 菜单或暂停界面，0.5～2.0 倍 |
| 全屏 | 菜单或暂停界面的“全屏”按钮 |

观察时 W/S 仍沿人物朝向前后移动，A/D 只让人物转身。松开镜头控制后暂留 1.25 秒；未继续移动或转身则保留视角，移动触发回正后会平滑完成，观察可随时打断。方向不好判断时先按 F，再用 W 前进，不需要同时操作两组方向键。

翻滚期间不能改变方向或手动取消；遇到障碍时停止位移，完成剩余动作后恢复控制。头顶空间不足时无法站起，翻滚空间不足时也会给出提示。当前没有跳跃或钻桌底操作。

切换应用、切走网页或退出鼠标捕获后，游戏会暂停。人物动作、领导动作和关卡计时都停止，回来后点击“点击继续”。重新开始会把人物和三位领导恢复到初始状态。

## 视线与声音

- **低头时可以寻找空隙。** 三位领导各自办公；抬头准备动作是预警，开始观察后才检查视线。
- **高柜和墙适合等待。** 它们能遮住站立身体；先确认身后和侧面没有露出，再观察下一段。
- **矮柜要配合蹲姿。** 是否安全由实际头部、胸口位置与实体遮挡决定。站姿和蹲姿在同一个位置可能有不同结果。
- **被确认发现就失败。** 连续暴露片刻后进入失败结算，不会转入追赶；躲回实际掩体后，尚未完成的发现进度会清除。
- **黄色区域是方向提示。** 地面提示会考虑遮挡，但它是粗略辅助，边缘不是绝对安全线。以身体是否真正被掩体挡住为准。
- **冲刺声会引起注意。** 附近领导可能抬头转向脚步声发生的位置；声音本身不会直接失败，也不会让领导隔墙知道你的实时位置。
- **三人独立判断。** 一位领导听见声音或看向你，不会把位置信息传给其他领导。

键盘、翻纸、记笔记、空调底噪以及动作和结算提示用于反馈状态。调低音量或静音不会改变领导的听觉判定；黄色视线和文字状态仍可帮助判断时机。

## 路线提示

| 区域 | 可以怎么做 |
|---|---|
| 01 工位区 | 从高柜后观察组长，蹲着沿矮柜通过；到尽头按指示向右进入走廊 |
| 02 主管办公室 | 在入口高柜后重新观察，沿矮柜通过主管门前，再向左进入下一条走廊 |
| 03 楼梯前厅 | 留意经理抬头，借最后一组高低柜接近绿色楼梯出口 |

不要一路冲刺：移动更快，也可能改变领导抬头的时间。失败后先看结算中是哪位领导发现了你，再调整这一区域的时机与姿态。

## 设置与运行范围

音量和灵敏度保存在本机。网页设置属于当前浏览器与站点，清理站点数据或使用不保留数据的浏览模式可能使其恢复默认；原生版使用本地配置文件。设置持久化也包含在正式包验收范围内。

当前未公开发布。1.0.1 已完成自由视角、视线频闪与贴墙卡顿修复的本地验证，最终 Chrome 真实键鼠通关和原生应用启动通过，范围见 [发布前稳定性测试记录](发布前稳定性测试记录.md)。Safari 26.6.2 仅有 1.0.0 真实操作烟测，没有完整整关成功／失败验收；旧版结果见 [历史交付记录](P5-P6交付测试记录.md)。itch.io 实际托管尚待账号或页面，Windows 未做本次实机验证，手机触屏不支持。

Safari 可能先用 Esc 关闭浏览器自身的捕获提示，再按一次才释放鼠标和暂停。退出全屏后等窗口恢复，再点击继续；若在窗口切换过程中被安全暂停，重新点击即可。

macOS 包属于未公证的开发构建，非 Mac App Store 分发；可能出现系统安全提示。最终支持范围与实测结果以更新后的发布验收记录为准。

计划网页上传包为 `builds/xiaban-release-web.zip`，具体构建命令、原生包和试玩入口见 [运行与导出](运行与导出.md)。不要通过双击导出的 `index.html` 运行网页版，应使用本地 HTTP 服务或实际托管页面。

反馈时请记录：所在区域、当时站姿或蹲姿、是否冲刺或翻滚、领导状态，以及预期与实际发生了什么。镜头遮挡、路口不清楚和意外发现判定尤其有帮助。
