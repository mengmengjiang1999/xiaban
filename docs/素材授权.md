# 素材与授权

更新日期：2026-09-22

## P2 人形与动画

P2 已使用下列实际下载的图形和动画资产，不再属于“全部人物由代码几何体构建”的范围。资源来源、版本、许可及修改已核查，源文件与再构建说明保存在 [角色源文件](../art/characters/README.md)。

| 资源 | 作者与版本／来源 | 许可与本轮处理 |
|---|---|---|
| 人体与骨架 | MakeHuman Community，MPFB **2.0.17**；[Blender 官方扩展页](https://extensions.blender.org/add-ons/mpfb/)、[版本许可](https://github.com/makehumancommunity/mpfb2/blob/v2.0.17/LICENSE.md) | 使用 CC0 图形资产生成约 1.75 米成人、53 根骨骼。插件代码与图形资产的许可分别处理，插件代码不进入游戏包 |
| 衣服、鞋、头发、眉毛、眼睛及皮肤 | [MakeHuman 官方 CC0 系统素材包](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html)：`male_casualsuit06`、`shoes01`、`short01`、`eyebrow001`、low-poly／brown eyes、所选成人皮肤 | 选中资源为 CC0；组合成一个着装成人，烘焙衣物遮蔽、补齐肩袖覆盖区身体遮蔽，保留蒙皮并减面，将短袖改为纯青绿色，纹理缩至最大 1K；修改明细随角色许可文件保存 |
| 六段骨骼动画 | **Quaternius Universal Animation Library Standard-1.0**；[作者在 Godot 官方资产商店的页面](https://store.godotengine.org/asset/quaternius/universal-animation-library/) | 包内 `License.txt` 标注 CC0 1.0；免费取得。选择 Idle、Walk、Sprint、Crouch Idle、Crouch Fwd、Roll，重定向、统一名称并处理脚底基准 |

动画包作者为 **Quaternius**，Godot 官方资产商店是本次实际获取渠道。下载 ZIP 的 SHA-256 为 `18ff1a7215f4852b320203e8aaf02a1578b5c8eef9027fbaedfcedc7b85a3ac2`；不把作者 itch.io 较新版本号记为本次 `Standard-1.0` 的版本。六段原始 clip 与项目名称的对应见 [人物资源选型](人物模型与动画资源选型.md)。

可编辑角色工程为 `art/characters/office_worker.blend`，运行模型为 `game/assets/characters/office_worker.glb`，处理记录为同目录 `office_worker.json`。角色许可及详细来源由 `game/assets/characters/LICENSES.txt` 汇总；P2 Web 打包脚本将其复制为 `CHARACTER-LICENSES.txt`。最终角色为 19,069 三角面、53 骨骼、6 个网格、7 个材质及 8 张最大 1K 纹理。两份重建输入的校验值保存在 `art/characters/source/SHA256.json`；完整 CC0 许可及原作者声明保存在 `art/characters/licenses/`。`game/` 外的开发源文件与 MPFB／Blender 工具不进入游戏包。
