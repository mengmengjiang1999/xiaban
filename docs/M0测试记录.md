## 本阶段处理的问题

1. 初次沙箱运行不允许写 Godot 的正常用户数据与缓存目录；取得本轮授权后使用正常权限重新导入，通过。
2. 初次导出 Universal macOS 构建缺少 ETC2/ASTC 导入设置；补齐项目纹理导入配置后重新导出、验证签名并运行，通过。
3. 浏览器使用 HTTP 服务加载，正确提供 WASM MIME；避免 `file://` 本地打开造成的限制。

以上为首次环境搭建时完成的配置调整。
