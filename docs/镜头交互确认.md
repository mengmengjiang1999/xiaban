## 1. 用户选择的构图

![六种镜头构图参考，用户选择 D](images/camera-view-options.png)

用户选择 **D：稍远右肩跟随**。以角色右后上方、站立时基本能看见全身的构图为初始参考，玩家可以调节镜头远近。镜头在角色右后方时，角色通常出现在画面偏左的位置。

本图由内置 imagegen 生成，用于构图沟通，不是游戏实机截图，也不代表最终人物、场景资产或画质要求。A～F 是选项，只有 D 被选为本阶段的基础构图。

## 2. 已确认的镜头行为

| 场景 | 镜头应该怎样表现 |
|---|---|
| 调节远近 | 使用鼠标滚轮拉近、拉远，D 为起始参考；具体距离范围待原型验证 |
| 左右环绕观察 | 按住鼠标右键拖动，镜头绕角色观察；本需求指环绕，不另外增加换肩功能 |
| 角色蹲下、站起 | 镜头不因动作自动下沉、抬升或改变俯仰；角色在画面内降低、恢复身体高度 |
| 角色翻滚 | 镜头不跟着身体翻转或摇晃，画面保持稳定；仍跟随角色实际移动的位置 |
| 角色水平转弯 | 镜头转向跟随人物水平朝向，回到该朝向后方的 D 构图；包括 A/D 原地转身 |
| 环绕后恢复行走 | 镜头平滑自动回正，不突然跳回默认朝向 |
| 随时快速回正 | 按 F 快速回到当前人物朝向后方的默认 D 构图，保留镜距 |

区分角色的**实际位置与水平转向**和**动画姿态**：镜头跟随前者，不直接继承头骨、脊柱或翻滚动画的旋转与上下起伏。翻滚姿态本身的旋转不视为角色水平转弯。

镜头仍需要正常的墙体避障；动作稳定不等于允许镜头穿墙。玩家主动调节和障碍处理应与动画带来的画面变化分别处理。

## 3. 已确认的操作与衔接

| 输入／状态 | 行为 |
|---|---|
| W / S | 沿人物朝向前进／倒退；倒退不改变人物朝向，不让镜头绕到人物前方 |
| A / D | 向左／右转身，镜头跟随人物水平朝向；不作横移，可原地转身 |
| 按住鼠标右键拖动 | 手动左右环绕观察优先，自动回正不与当前拖动争夺镜头 |
| 结束环绕、恢复行走 | 平滑自动回到人物朝向后方的 D 构图；若松开右键时仍在行走，同样恢复自动回正 |
| 鼠标滚轮 | 调节远近 |
| F | 随时快速回正，无需等待普通自动回正过程 |
| 蹲起／翻滚 | 镜头保持稳定，不继承动画姿态；仍跟随角色实际位置 |

用户已明确选择“平滑自动回正；快捷键可随时快速回正”，并接受“右键拖动＝环绕、滚轮＝远近、F＝回正”的操作。

“回正”指镜头方位回到当前人物朝向后方的 D 构图，不重新设置用户调过的镜头距离。静止、倒退和原地转身时均以当前人物水平朝向为参照；出生时使用初始人物朝向。右键观察不改变人物朝向，W/S 的前后方向也不随观察镜头改变。

2026-09-20 的“跟随行走方向”是历史表述，已由 2026-09-21 的 W/S 前后移动、A/D 转身及人物朝向参照取代，不能继续按实际位移方向回正。

具体镜距范围、跟随速度和自动／快速回正时间仍待原型验证，不把示意图当作精确相机参数。镜头交互的上述关键问题已答复，不能继续标成待确认；后续若出现新的不明确行为，按下面的沟通约定先问再实现。

- 调整视角、动作或交互规则时，先展示具体提案或示意图，确认后再实现。

## 5. 确认后的验证方向

- 用同一位置的站立／蹲伏对照，检查画面没有因动作自动升降或倾斜。
- 用连续翻滚演示检查画面不随角色翻转，同时角色实际移动时仍能被跟随。
- 用 A/D 原地转身、前进中转身和倒退中转身检查镜头跟随当前人物朝向；只按 S 时镜头不反转。
- 环绕观察后检查 W/S 仍参照人物朝向，镜头观察角度不改变角色前后方向。
- 右键环绕期间不能被自动回正打断；结束观察并恢复行走后平滑回正，F 可随时快速回正。
- 调整远近后触发自动回正和 F 回正，检查不会把玩家选择的距离意外重置。
- 在远近、左右调节后重复贴墙与窄门检查，确保调节范围和避障兼容。

上述基础控制与镜头分离已实现并通过验证，试玩发现的窄角镜头跳动与共面墙面频闪已修复。86 项基础回归、8 项几何回归、15 项镜头稳定性检查（包含原路线 9 项）及新版 Chrome 43 项浏览器检查通过；镜头稳定性另覆盖 120 FPS 渲染与 60 FPS 物理交错。P1 本轮完成，测试模式及平台边界见 [P1 测试记录](P1测试记录.md)，旧版测试不能替代本清单。

原型镜距为 1.8～7.0 米，默认 4.8 米，俯角 14°，右偏 0.65 米；实际遇障碍可缩得更近。镜头距人物锚点小于 1.35 米时胶囊逐渐淡化，0.5 米以下保留 0.12 透明度，避免挡住通路；只改变显示，不改变实体碰撞。这些是当前可调参数，后续按试玩意见调整。
