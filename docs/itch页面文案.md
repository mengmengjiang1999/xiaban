## 简短简介

## 页面正文

### 今天，也要准时下班

你是一名准备离开工位的程序员。通往楼梯口的路上，工位组长还在敲键盘，办公室主管正在翻阅文件，经理也没放下手中的笔。

《下班》是一款单人第三人称 3D 潜行小游戏。从工位区出发，穿过办公室门前，再经过楼梯前厅。三位领导各自办公、抬头观察，互不通报你的位置。停在高柜后看看时机，蹲在矮柜后慢慢移动，找准方向再翻滚通过。

### 看清楚，再走

领导低头办公时不会发现你；抬头后，头部或胸口持续暴露片刻就会被确认发现，本次下班失败。可以立即重新开始，再试一个时机。

黄色地面区域帮助你看清领导的观察方向。真正决定是否被发现的是人物姿态和实际遮挡：墙与高柜能遮住站立的身体，矮柜则需要蹲下。冲刺的脚步会让附近领导抬头转向声源，声音本身不会直接判你失败。

沿着办公室里的导向牌，穿过三段区域，到达绿色楼梯出口，就能结束今天的工作。

### 操作

请使用电脑、键盘和鼠标游玩。

| 操作 | 按键或方式 |
|---|---|
| 朝人物前方移动／倒退 | W／S |
| 向左／向右转身 | A／D |
| 蹲下／站起 | C |
| 冲刺 | 站立时按住 Shift + W |
| 向人物前方翻滚 | 蹲下后按 Space |
| 自由观察 | 按住鼠标右键并左右拖动 |
| 调整镜头距离／回正 | 鼠标滚轮／F |
| 暂停 | Esc；返回后点击“点击继续” |

翻滚开始后方向锁定，落稳后才能继续操作；碰到障碍会停止前进。菜单和暂停界面可以调整游戏音量、镜头灵敏度以及切换全屏。设置保存在本机，切换应用或失去焦点时游戏会自动暂停。

### 这一关有什么

- 工位区、办公室门前、楼梯前厅组成的一条完整潜行路线。
- 有不同衣着与配饰的主角和三位领导，以及敲键盘、翻文件、记笔记的办公动作。
- 肩后镜头、蹲行、冲刺和翻滚，结合高低掩体寻找行动时机。
- 木质家具、地毯、墙面导向牌和下班时分的办公室氛围。
- 原创程序音效、发现提示、成功与失败结算，以及随时重试。

本版包含一个完整第一关。首次游玩的时间会受观察和重试次数影响；欢迎反馈不清楚的路口、看不清的视线提示，以及任何让你意外的发现判定。

### 试玩范围

面向电脑键盘和鼠标设计，暂不支持手机触屏。当前版本已在本机 Chrome 149 完成整关成功、失败、重试与设置保存验证；Safari 26.6.2 通过基础操作烟测，完整整关尚未验证。Windows 未做本次实机验证。

可选 macOS 下载包已在 Apple M4 上验证启动，采用本地开发签名，未公证，非 Mac App Store 分发。
