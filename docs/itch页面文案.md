## 页面正文

### 今天能准点下班吗？

你是一名准备离开工位的程序员。下班路上，工位对面的领导还在转头巡视，办公室里的领导不时出来走动，楼梯口还有最后一道考验。

《准点下班》是一款轻度潜行的 3D 小游戏。领导的视野会直接显示在地面上：看清方向，借助墙和高柜掩护，找到离开的机会。

![《准点下班》第一关](images/level-one-game.png)

### 怎么玩

| 操作 | 按键 |
|---|---|
| 移动 | WASD／方向键 |
| 跑步 | 按住 Shift |
| 暂停／继续 | Esc |
| 结算后快速重试 | R |

点击“开始下班”后，穿过办公区，抵达绿色 **EXIT / 下班** 区域即为成功。

墙和高柜能挡住领导的视线，矮桌只能挡路。进入视野时警戒值会增长；警戒满后，领导才会追赶。被追时可以跑向掩体，尝试甩开领导，被抓住后随时再来一次。

菜单和暂停界面提供音量与全屏按钮。切换到其他应用时，游戏会自动暂停。

### 这一版有什么

- 一个完整的小关卡，包含工位区、办公室走廊和楼梯口。
- 三位行为不同的领导，以及可见的视野和警戒提示。
- 简单的 3D 人物、办公室家具和音效。
- 开始、暂停、成功、失败和重试流程。

这是第一关的短小初版。熟悉路线后的观察通关实测约 30 秒；首次游玩时长尚未统计，也会随探索和重试次数而不同。欢迎尝试不同路线，看看能否更从容地离开办公室。

### 试玩前请了解

请使用电脑和键盘游玩。当前已验证的浏览器为 Mac 上的 Chrome／Chromium；Safari 和 Windows 仍待验证。暂未提供手机触屏操作。

本版只有一关，人物和场景采用简单造型。欢迎反馈操作不顺手、视野看不清、被发现原因不明确等体验。
